# 📖 Sobre o Projeto

Este projeto tem como objetivo aplicar conceitos de Engenharia de Requisitos no desenvolvimento da especificação de um sistema web/mobile voltado à preparação de estudantes para o ENADE.

A proposta busca auxiliar estudantes através de questões comentadas, simulados, estatísticas de desempenho e recursos colaborativos de aprendizagem.

---

# 🎯 Objetivo Geral

Aplicar Engenharia de Requisitos na especificação de um sistema educacional para apoio à preparação de estudantes para o ENADE.

---

# ✅ Objetivos Específicos

- Realizar elicitação de requisitos
- Desenvolver documento SRS
- Criar diagramas UML
- Elaborar protótipos de interface
- Organizar requisitos funcionais e não-funcionais
- Aplicar conceitos da disciplina em um projeto real

---

# 🧠 Funcionalidades do Sistema

## 📚 Banco de Questões
Questões organizadas por:
- Ano
- Curso
- Área de conhecimento
- Formação geral
- Conhecimento específico

---

## ⏱ Simulados Cronometrados
Simulados com tempo real para prática semelhante ao exame.

---

## ✅ Gabarito Comentado
Explicações detalhadas das respostas das questões.

---

## 📊 Estatísticas de Desempenho
Análises de desempenho por área de conhecimento.

---

## 💬 Fórum de Discussão
Espaço para interação entre estudantes.

---

## 🔐 Sistema de Login
Cadastro e autenticação de usuários e administradores.

---

# 🛠 Metodologia Utilizada

O projeto seguirá as etapas da Engenharia de Requisitos:

1. Pesquisa exploratória
2. Elicitação de requisitos
3. Validação de requisitos
4. Modelagem UML
5. Prototipação de interfaces
